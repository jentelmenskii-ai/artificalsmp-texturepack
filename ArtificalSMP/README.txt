CUBE INSIDE - ресурс-пак + TAB

Для Minecraft 1.21.1 / pack_format 34.

1. Ресурс-пак:
   - закинь cube_inside_resourcepack.zip на хостинг с прямой ссылкой;
   - подключи его через плагин принудительной загрузки ресурспака.

2. TAB:
   - открой plugins/TAB/config.yml;
   - вставь содержимое tab-scoreboard.yml;
   - перезагрузи TAB командой /tab reload.

3. Важный символ:
   \uE000

   TAB отправляет этот символ, а ресурспак превращает его в логотип.

4. Если логотип слишком высокий/низкий:
   меняй ascent в:
   assets/server/font/logo.json

5. Если нужен другой логотип:
   замени:
   assets/server/textures/logo.png

В этой версии панель использует логотип + динамические данные TAB.
Список нескольких игроков как на исходном скриншоте требует отдельной логики,
потому что обычная строка scoreboard не умеет автоматически создавать строки
по каждому онлайн-игроку.
